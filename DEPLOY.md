# Як запустити сайт у продакшн

Сайт — це готові HTML-сторінки плюс одна серверна функція, яка приймає заявки з форми.
Бази даних немає: заявки не зберігаються, а одразу пересилаються в Telegram і/або на пошту.

| Частина | Де живе |
|---|---|
| Сайт (Angular, пререндер у HTML) | **Vercel** |
| Прийом заявок `/api/lead` | **Vercel Functions** (у тому ж проєкті) |
| Сповіщення | **Telegram-бот** і/або **Resend** (email) |

Потрібен хоча б один канал сповіщень — Telegram або пошта. Найпростіше почати з Telegram.

---

## 1. Telegram — заявки в месенджер

1. У Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай назву.
   Він видасть токен виду `123456789:AA...` → це `TELEGRAM_BOT_TOKEN`.
2. Куди слати заявки:
   - **Собі особисто:** напиши своєму боту будь-яке повідомлення.
   - **У групу** (напр. «Заявки з сайту» для кількох менеджерів): створи групу, додай бота, напиши в групі будь-що.
3. Відкрий у браузері `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайди `"chat":{"id": ...}`.
   Це число (для груп від'ємне, напр. `-100123...`) → `TELEGRAM_CHAT_ID`.
   Кілька чатів — через кому: `111111,-100222222`.

## 2. Resend — заявки на пошту (необов'язково)

1. Зареєструйся на [resend.com](https://resend.com).
2. **Domains → Add domain** → свій домен → додай показані DNS-записи в панелі реєстратора домену. Дочекайся статусу **Verified**.
3. **API Keys → Create** → це `RESEND_API_KEY`.
4. `LEAD_EMAIL_FROM` — адреса на твоєму домені, напр. `GeniusDev <zayavky@твій-домен.com.ua>`.
   `LEAD_EMAIL_TO` — куди слати, напр. `geniusdevgnb@gmail.com` (кілька — через кому).

> Без власного домену Resend дозволяє слати лише на пошту, з якою ти реєструвався.
> Якщо пошта не потрібна — просто не заповнюй ці змінні.

## 3. Vercel — хостинг

> ⚠️ Безкоштовний тариф Vercel (Hobby) дозволений лише для некомерційних сайтів. Сайт компанії з послугами
> вважається комерційним, тож потрібен тариф **Pro** (актуальна ціна на [vercel.com/pricing](https://vercel.com/pricing)).

1. Зареєструйся на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project** → обери репозиторій `build-site` → **Import**.
   Налаштування збірки вже лежать у `vercel.json`, нічого міняти не треба.
3. Перед **Deploy** розгорни **Environment Variables** і додай:

   | Змінна | Значення | Обов'язкова |
   |---|---|---|
   | `SITE_URL` | твій домен, напр. `https://geniusdev.com.ua` | так |
   | `TELEGRAM_BOT_TOKEN` | крок 1 | для Telegram |
   | `TELEGRAM_CHAT_ID` | крок 1 | для Telegram |
   | `RESEND_API_KEY` | крок 2 | для пошти |
   | `LEAD_EMAIL_FROM` | крок 2 | для пошти |
   | `LEAD_EMAIL_TO` | крок 2 | для пошти |

4. **Deploy**. Через 1–2 хвилини сайт буде на адресі `назва-проєкту.vercel.app`.
5. Перевір: відкрий сайт → залиш тестову заявку → вона має прийти в Telegram (і на пошту, якщо налаштовано).

Кожен `git push` у гілку `main` автоматично перевикладає сайт. Push в іншу гілку створює окреме прев'ю-посилання.

## 4. Домен

1. Vercel → проєкт → **Settings → Domains → Add** → введи домен.
2. Vercel покаже DNS-записи, які треба додати в панелі реєстратора домену. Після оновлення DNS
   (від кількох хвилин до кількох годин) HTTPS-сертифікат з'явиться автоматично.
3. Якщо змінився `SITE_URL` — онови його у Vercel → **Redeploy**.

## 5. Google

- Додай сайт у [Google Search Console](https://search.google.com/search-console) і вкажи там `https://твій-домен/sitemap.xml`.
- Створи або онови профіль компанії в Google Maps (Google Business Profile) з посиланням на сайт.

## Як змінювати контент

Після будь-якої зміни: commit → push у `main` → Vercel сам перезбере сайт (1–2 хв).

| Що | Де |
|---|---|
| Послуги: назви, тексти, ціни, фото, порядок | `src/app/core/data/services.json` |
| Сховати послугу | там же: `"is_published": false` |
| Телефони, пошта, «понад 7 років» | `src/app/core/site.ts` |
| Тексти головної (переваги, кроки, FAQ) | `src/app/site/home/home.ts` і `home.html` |
| Фото послуг | `src/assets/` (WebP, ~1600 px завширшки), шлях у полі `image_url` |

Текст послуги (`body`) пишеться в Markdown: `## Заголовок`, `- пункт`, `1. крок`, `**жирний**`,
`> текст` — жовтий інфоблок. Рядки розділяються `\n` (так уже зроблено в наявних послугах).

## Якщо щось не працює

| Симптом | Що перевірити |
|---|---|
| Після надсилання форми — «Не вдалося надіслати заявку» | Задано хоча б один канал (`TELEGRAM_*` або `RESEND_*`/`LEAD_EMAIL_*`); Vercel → Logs → функція `api/lead` |
| Заявки не приходять у Telegram | Чи писав ти боту / чи бот доданий у групу; чи правильний `TELEGRAM_CHAT_ID` |
| Не приходять листи | Домен у Resend має статус **Verified**; `LEAD_EMAIL_FROM` на цьому домені |

## Локальна розробка

Потрібен Node.js 22.22+ або 24.15+ ([nodejs.org](https://nodejs.org), версія LTS).

```bash
npm ci
npm start          # http://localhost:4200
npm run build      # продакшн-збірка в dist/mysite/browser
npm test           # тести прийому заявок
```

Локально (`npm start`) серверної функції немає, тож форма покаже, що це прев'ю, і нічого не надішле.
Щоб перевірити заявки локально з реальними сповіщеннями: `npx vercel dev` (потрібен `.env`, див. `.env.example`).
