# Як запустити сайт

Сайт статичний: усі сторінки збираються в готові HTML-файли. Бази даних і адмінки немає.
Єдина «серверна» частина — прийом заявок з форми (`/api/lead`), який пересилає їх у Telegram і на пошту.

Є два варіанти хостингу. Обидва дешевші за Vercel Pro:

| | **A. Cloudflare Pages** (рекомендовано) | **B. Звичайний хостинг із PHP** |
|---|---|---|
| Ціна | 0 грн, комерційні сайти дозволені | Те, що ти вже платиш за хостинг |
| Домен | Купується окремо (у будь-якого реєстратора) | Зазвичай у того ж хостера |
| Оновлення сайту | Автоматично після `git push` | Вручну: зібрати й залити файли через FTP |
| Заявки | Telegram + пошта через Resend | Telegram + пошта через `mail()` хостингу |
| HTTPS, швидкість | Автоматично, CDN по всьому світу | Залежить від хостера |

Спершу — Telegram-бот (потрібен в обох варіантах), потім обраний варіант.

---

## 1. Telegram-бот для заявок

1. У Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай назву.
   Він видасть токен виду `123456789:AA...` — це **токен бота**.
2. Куди слати заявки:
   - **собі:** напиши своєму боту будь-яке повідомлення;
   - **у групу:** створи групу, додай туди бота, напиши в групі будь-що.
3. Відкрий у браузері `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайди `"chat":{"id": ...}`.
   Це число (для груп воно від'ємне, напр. `-100123...`) — **chat id**. Кілька чатів записуються через кому.

## Варіант A. Cloudflare Pages (безкоштовно)

### A1. Підключити репозиторій
1. Зареєструйся на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages → Create → Pages → Connect to Git** → обери репозиторій `build-site`.
3. Налаштування збірки:
   - Framework preset: **None**
   - Build command: `npm run build`
   - Build output directory: `dist/mysite/browser`
   - Production branch: `main`
4. **Environment variables** (тут же або пізніше в **Settings → Variables and Secrets**):

   | Змінна | Значення | Тип |
   |---|---|---|
   | `SITE_URL` | `https://твій-домен.com.ua` | Text |
   | `TELEGRAM_BOT_TOKEN` | токен з кроку 1 | **Secret** |
   | `TELEGRAM_CHAT_ID` | chat id з кроку 1 | Text |
   | `RESEND_API_KEY` | див. A3 (необов'язково) | **Secret** |
   | `LEAD_EMAIL_FROM` | див. A3 | Text |
   | `LEAD_EMAIL_TO` | напр. `geniusdevgnb@gmail.com` | Text |

5. **Save and Deploy**. За 1–2 хвилини сайт буде на `назва-проєкту.pages.dev`.
   Перевір: залиш тестову заявку — вона має прийти в Telegram.

Далі кожен `git push` у `main` автоматично оновлює сайт. Push в іншу гілку — окреме прев'ю-посилання.

### A2. Домен
- **Домен уже є в іншого реєстратора:** Pages → проєкт → **Custom domains → Set up a domain**.
  Cloudflare запропонує або перенести DNS домену в Cloudflare (найпростіше, безкоштовно),
  або додати CNAME-запис у панелі поточного реєстратора. HTTPS увімкнеться автоматично.
- **Купити новий:** у Cloudflare (**Domain Registration**) домени продаються за собівартістю,
  але `.com.ua` там немає — для українських доменів підійде будь-який український реєстратор.

Після підключення домену онови змінну `SITE_URL` і натисни **Retry deployment** (або зроби push).

### A3. Пошта через Resend (необов'язково)
1. Зареєструйся на [resend.com](https://resend.com) → **Domains → Add domain** → додай DNS-записи, які він покаже.
2. **API Keys → Create** → це `RESEND_API_KEY`.
3. `LEAD_EMAIL_FROM` — адреса на твоєму домені, напр. `GeniusDev <zayavky@твій-домен.com.ua>`.

Якщо пошта не потрібна — не заповнюй ці три змінні, заявки йтимуть лише в Telegram.

## Варіант B. Звичайний хостинг із PHP

Підійде майже будь-який хостинг із PHP 8.1+ і Apache (так працює більшість українських хостерів).

### B1. Зібрати сайт на своєму комп'ютері
Потрібен Node.js 22.22+ або 24.15+ ([nodejs.org](https://nodejs.org), версія LTS).

```bash
npm ci
echo SITE_URL=https://твій-домен.com.ua > .env
npm run build:php
```

З'явиться папка `dist/upload` — це готовий сайт разом з обробником форми.

### B2. Залити на хостинг
1. У панелі хостингу переконайся, що для сайту вибрано **PHP 8.1 або новіший**.
2. Через FTP або файловий менеджер хостингу залий **вміст** папки `dist/upload` у корінь сайту
   (зазвичай `public_html` або `www`). Разом з усіма файлами має потрапити прихований `.htaccess`.
3. На сервері в папці `api` скопіюй `config.example.php` у `config.php` і заповни:
   ```php
   'site_url' => 'https://твій-домен.com.ua',
   'telegram_bot_token' => '123456789:AA...',
   'telegram_chat_id' => '123456789',
   'mail_to' => 'geniusdevgnb@gmail.com',
   'mail_from' => 'zayavky@твій-домен.com.ua',
   ```
   `config.php` відвідувачі не бачать: PHP виконується, а `.htaccess` додатково закриває до нього доступ.
4. Увімкни HTTPS у панелі хостингу (Let's Encrypt зазвичай безкоштовний).
5. Перевір: відкрий `https://твій-домен/services/spayka-trub`, залиш тестову заявку.

Для пошти скрипт використовує стандартну функцію `mail()` хостингу. Щоб листи не потрапляли в спам,
`mail_from` має бути на твоєму домені (часто таку скриньку треба спершу створити в панелі хостингу).

**Оновлення сайту:** після змін — знову `npm run build:php` і залити вміст `dist/upload`
(файл `api/config.php` на сервері не перезаписується, бо в збірці його немає).

## Як змінювати контент

| Що | Де |
|---|---|
| Послуги: назви, тексти, ціни, фото, порядок | `src/app/core/data/services.json` |
| Сховати послугу | там же: `"is_published": false` |
| Телефони, пошта, «понад 7 років» | `src/app/core/site.ts` |
| Тексти головної (переваги, кроки, FAQ) | `src/app/site/home/home.ts` і `home.html` |
| Фото послуг | `src/assets/` (WebP, ~1600 px завширшки), шлях у полі `image_url` |

Текст послуги (`body`) пишеться в Markdown: `## Заголовок`, `- пункт`, `1. крок`, `**жирний**`,
`> текст` — жовтий інфоблок. Рядки розділяються `\n` (так уже зроблено в наявних послугах).

Після змін: варіант A — commit і push; варіант B — `npm run build:php` і залити файли.

## Якщо щось не працює

| Симптом | Що перевірити |
|---|---|
| Після надсилання форми — «Не вдалося надіслати заявку» | Токен і chat id; чи писав ти боту / чи бот у групі |
| «Сервіс заявок не налаштовано» (варіант B) | Чи створено `api/config.php` на сервері |
| Сторінки послуг відкриваються як 404 (варіант B) | Чи залитий `.htaccess` і чи хостинг на Apache з `mod_rewrite` |
| Заявки в Telegram є, а листів немає | A: домен у Resend **Verified**; B: `mail_from` на твоєму домені, чи дозволяє хостинг `mail()` |
| Логи (A) | Cloudflare → проєкт → **Functions → Real-time logs** |

## Локальна розробка

```bash
npm ci
npm start          # http://localhost:4200
npm test           # тести прийому заявок
```

Локально (`npm start`) обробника форми немає, тож форма покаже, що це прев'ю, і нічого не надішле.
